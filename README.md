# CommonGround — A Better Way for People to Meet

> **University Project Prototype & Ethical Social Computing Showcase**  
> *"Better connections begin with common ground."*

CommonGround is a consent-first, interest-driven connection platform designed to help compatible people discover each other through shared activities, values, and intentions rather than superficial appearance, swiping, or popularity algorithms.

---

## 🌟 The Core Problem We Solve

Traditional dating and social apps systematically fail modern users across five critical dimensions:

1. **Superficiality & Lookism:** Snap judgments based on edited photos commodify humans into playing cards, disregarding character, intellect, and passions.
2. **Intention Ambiguity:** Users are thrown into a single pool with mismatched goals (casual dating vs. platonic friendship vs. hobby partners).
3. **Rejection & Ghosting Anxiety:** Asymmetric dynamics and silence loops make introverted, shy, or neurodivergent individuals feel isolated.
4. **Safety & Harassment:** Unsolicited direct messages and unchecked boundaries expose users to spam, pressure, and boundary violations.
5. **Manipulative Gamification:** Black-box ELO attractiveness algorithms and artificial urgency keep users addicted rather than connected.

---

## 💡 The CommonGround Solution

CommonGround discards the swiping model entirely and introduces:

- **A. Shared-Interest Discovery:** Connect through activities (Ceramics, Bouldering, Indie Game Dev, Speculative Fiction, Analog Photography).
- **B. Mutual Introduction System:** Low-pressure, contextual invitations with tailored icebreakers. Recipients can accept or quietly decline with **zero public rejection count or penalty**.
- **C. Explainable Compatibility Engine:** A deterministic, 100% transparent formula:
  - **Shared Interests:** 40%
  - **Compatible Intentions:** 30%
  - **Shared Core Values:** 20%
  - **Communication Preferences (Pace, Style, Energy):** 10%
  *(No sensitive characteristics or black-box neural networks).*
- **D. Safety & Boundary Center:**
  - One-tap **Pause Discovery** mode for social battery recovery.
  - Granular visibility & request filters.
  - One-click blocking with instant removal from discovery.
  - Local simulated moderation audit log.
- **E. Inclusive Onboarding:** A respectful 6-step wizard that honors personal pacing, pronouns, and boundaries.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+ or v24+)
- npm (v9+)

### Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Launch Vite development server
npm run dev

# 3. Open in your browser
http://127.0.0.1:5173/
```

### Production Build & Preview

```bash
# Compile and bundle
npm run build

# Preview the production build
npm run preview
```

## 🎓 University Presentation & Defense

Click the **"Project Defense"** button in the top navigation bar at any time to open the built-in presentation deck covering:
1. **Social Diagnosis:** Why algorithmic swiping creates isolation.
2. **System Architecture:** How the mutual consent gate operates.
3. **Mathematical Model:** Detailed 40/30/20/10 scoring weights.
4. **Human Factors:** Protection for neurodivergent and introverted users.
5. **Academic Limitations:** Stated vs. revealed preferences, cold-start density, and in-person meeting safety.
